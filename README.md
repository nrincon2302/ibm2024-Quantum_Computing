Este repositorio contiene los archivos del **Examen Parcial** y del **Proyecto Final** del curso de verano de 2024.

Se incluyen implementaciones breves y simulaciones desarrolladas en notebooks de Jupyter, junto con descripciones teóricas de los procesos y enfoques adoptados, principalmente enfocados en la Computación con Compuertas Cuánticas para conformar circuitos cuánticos.

El proyecto final consiste en una implementación de la **Paradoja de Monty Hall**, ejecutada mediante *Jobs* en la plataforma **IBM Quantum**, utilizando el framework **Qiskit**. 
Se simula probabilísticamente cómo la decisión de cambiar de puerta no equivale a una probabilidad del 50%, sino que incrementa las posibilidades de ganar al **66% (2/3)**, lo cual se evidencia y analiza desde una perspectiva cuántica y estadística.

## Requisitos

* Python 3.8 o superior
* [Qiskit](https://qiskit.org/)
* Cuenta en [IBM Quantum](https://quantum-computing.ibm.com/) con acceso a recursos de ejecución (Jobs)
* Jupyter Notebook o JupyterLab (o su equivalente en instalación de Anaconda)

## Instalación rápida

```bash
pip install qiskit jupyter
```

## Ejecución

1. Clona este repositorio:

   ```bash
   git clone https://github.com/nrincon2302/ibm2024-Quantum_Computing
   cd ibm2024-Quantum_Computing
   ```

2. Ejecuta Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

3. Abre los archivos `.ipynb` para explorar las simulaciones y análisis.
